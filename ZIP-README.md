# Atlas Global South AI Coalition — Complete Repository Package

This archive contains the complete AI-editable static website repository.

## Included

- Institutional website source in `src/`
- Shared visual system in `src/styles/`
- Complete member registry in `data/members.json`
- Country/member directory logic
- 163 individual member folders in `Atlas_Coalition_Members/`
- Founding Committee data and validation
- Forms, contributions workflow and documentation
- Route manifest, static route shells and logo assets
- README, architecture notes and contributor guidance

## Deliberately excluded

- `.git/` repository metadata
- `web3forms-config.js`, because it contains a local access key

To enable forms locally, create `web3forms-config.js` from the included `web3forms-config.example.js` and add the appropriate access key privately.
