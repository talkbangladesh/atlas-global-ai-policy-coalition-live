# Country directory guide

Country pages are generated from verified `country` assignments and `data/countries.json`; no country or representative is inferred from names or biography text. The authoritative uploaded JSON currently reports `countries_verified: 0` and all 163 country values as null, so the public directory displays all profiles as **Country Verification Pending** until a reliable source is approved.

The current route structure is `/countries/`, `/countries/{country-slug}/`, `/members/` and `/members/{member-slug}/`. Country code, flag asset, member count and representative relation should be added only after source verification. Membership classifications remain exactly 142 Founding Member and 21 Member.
