# Real-content checklist

The redesign intentionally renders only source-audited content. Before launch, supply or confirm the following:

- **Country data:** authoritative 55-country list, region assignments, member counts and map coordinates/paths for `data/countries.json`.
- **Leadership content:** approved Co-Chair pull quotes and any final short biographies if the current member biographies are not the intended public copy.
- **Affiliations:** permission to use institution logos; the current strip uses text wordmarks because no approved logo files were supplied.
- **Publications:** published titles, publication dates, types, PDF files and verified file sizes for `data/publications.json`.
- **News and events:** approved news summaries plus upcoming event dates, times, time zones, locations, registration links and calendar links for `data/news.json` and `data/events.json`.
- **Brand and contact:** final share image, accessibility statement URL, privacy/terms URLs, official LinkedIn URL, contact email and newsletter destination.
- **Languages:** reviewed Spanish, French and Arabic translations beyond the interface scaffold in `src/i18n/`.
